# Verdant House

A fictional Victorian glass conservatory in Marlowe Park, Portland — a four-page
concept site: home, visit, the living collection, and what's on.

Hand-coded (HTML/CSS/JS, no framework). Type: Young Serif, Karla, Cormorant
Garamond italic. Motion: an opening-doors intro on first visit, arched
leaf-curtain wipes between pages, images that grow out of the ground on scroll,
and a slow light sweep in the hero glass. Respects `prefers-reduced-motion`.

All photography is AI-generated for this study; the garden is not real.
